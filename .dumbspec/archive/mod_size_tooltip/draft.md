Создаем новый мод, называется Size In Tooltip


Смысл в том чтобы добавить в тултип рядом с указателем мыши размер выделеной области.
Например, при инструментах Отменить, Разрушить, Копать и тд когда тянешь их и создаешь прямоугольник выделения, то внутри прямоугольника выводится его размер, например:
```
15x4
60 (в клетках)
```

В некоторых случаях размер не виден, например, слишком большой прямоугольник или тултип загораживает размеры.
Я хочу продублировать эту информацию в тултип.

Не знаю как удобнее добавить. на данный момент, например, при инструменте "Копать" выводится следующееЖ

```
КОМАНДА "КОПАТЬ"
(иконка лкм мыши) ПЕРЕТАЩИТЬ  (иконка пкм мыши)  НАЗАД
```

Я вижу это так в тултипе:

```
КОМАНДА "КОПАТЬ"
РАЗМЕР: 
15x4
60 (в клетках)
(иконка лкм мыши) ПЕРЕТАЩИТЬ  (иконка пкм мыши)  НАЗАД
```
