- **Fix A postfix signature** (Stage 1.5): the core `IsValidBuildLocation` int overload is `(GameObject, int, Orientation, bool, out string)`; mirror the proven in-game pattern of the existing 6-arg postfix (which drops the `out string` and everything after it): `Postfix(BuildingDef __instance, GameObject __0, int __1, Orientation __2, bool __3, ref bool __result)`. The 6-arg postfix's dropped-params shape is proven to work in this 0Harmony v2 build (the plan actually placed in the user's test), so the identical shape here is the safe choice.

Prefix signature is clean: `Prefix(Constructable __instance, UtilityConnections __0, WorkerBase __1)` (no out/byref params).

- **Same-def plan removal** (Stage 2): the native fallback stores the plan before the postfix sees it; removal = write null to the `Grid.Objects` replacement-layer slot and return false — safe because the slot is only read by the construction queue.
