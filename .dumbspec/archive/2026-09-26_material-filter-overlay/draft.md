# Draft: MaterialFilterOverlay

Дополнительный фильтр по материалу в оверлее чтобы легче найти нужный материал (например, нужно визуально найти постройки из золота и разобрать их чтобы получить золото. актуально для игры с малым количеством ресурсов

Есть ванильный оверлей F4 (Схема материалов), см скрин.

[скрин: image.png — окно "СХЕМА МАТЕРИАЛОВ" со списком категорий: Все, Металл, Минерал, Фильтрующий материал, Расходуемая руда, Органика, Пакотная земля, Плавкое, Газ, Жидкость, Разное — с чекбоксами]

При выбранном типе материала, например Металл, у нас появляется возможность задать подфильтры, которые скрываются под 

У каждого типа появляется плюсик, где раскрываются список со всеми возможными материалами данного типа.

Типа так
```
[+] Металл [*]
   Медь [ ]
   Медная руда [ ]
Минерал [ ]
```

Кнопка + появляется только у выбранного типа был выбран тип, например Металл, если переключиться, например, на Минерал, то предыдущая фильтрация обнуляется и убирается кнопка и дерево схлопывается, затем появляется кнопка [+] у Минерала

И соответственно напротив каждого конкретного материала можно поставить галочку. Оверлей соотвественно фильтрует более узко по выбранным материалам, можно выбрать 1 и более материала данного типа
