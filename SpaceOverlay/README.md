Adds a toggle to the in-game overlay menu (the row of icons next to Oxygen, Power, etc.). When enabled, cells exposed to space (the ones with no backwall behind them — the cells the game marks with the "Space exposure" status) on the main map are covered with a muted translucent red tint, so you can see where space hides behind blocks at a glance instead of hovering the mouse and reading the tooltip.

# Features

* Toggle in the in-game overlay menu: the 16th icon in the row, next to Oxygen, Power, etc. (no hotkey — just click it)
* Muted translucent red tint over every cell of the active world that is in the "Space" biome zone, so space behind blocks is visible without hovering and reading the "Space exposure" tooltip
* Buildings standing at the space boundary (walls, doors, drywall) are tinted too — you can see that space is behind them
* The tint is bounded to the active world — it never spills into the space outside the map

# Limitations

* Main map only — the minimap is not tinted
* The tint color is fixed and cannot be changed
