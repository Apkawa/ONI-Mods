# 2026-09-22_mod-cover-script: скрипт генерации обложки мода

**Created:** 2026-09-22T19:38:09+03:00

## Scope

**В scope:**
- Скрипт `scripts/generate_cover.py` на Python (Pillow), генерирует обложку мода OXI.
- CLI (argparse): позиционные аргументы — путь к входному изображению (скриншот функциональности мода), текст названия мода, путь к выходному PNG. Опциональный `--size` (макс. 900, default 900).
- Вход: любое растровое изображение (jpg/png) → центральный кроп до квадрата, resize до 900x900 (Lanczos).
- Текст: строки обложки определяются явно — в аргументе текста поддерживается литеральная последовательность `\n` (в шелле передаётся как `"Size \\nIn Tooltip"`), которую скрипт переводит в перенос строки. Если переносов нет — авто-разбивка по пробелам (по одному слову на строку). Строки центрированы по горизонтали и равномерно распределены по вертикали сверху вниз.
- Стиль: белый жирный текст с чёрной обводкой. Жирность имитируется обводкой (Bold-версии шрифта нет).
- Автомасштаб размера шрифта: при длинных словах размер уменьшается, чтобы слово помещалось в ~85% ширины обложки; базовый размер подбирается от количества слов.
- Выход: PNG 900x900.

**Out of scope:**
- Интеграция в пайплайн сборки мода (только ручной вызов).
- Иконки, авторы, версия, локализация текста.
- Тестовый скриншот не коммитится (остаётся в `.tmp/`, gitignored); коммитится только скрипт.

## Approach

- Один файл `scripts/generate_cover.py`, стандартная библиотека + Pillow 10.2.0, argparse.
- Обводка через `stroke_width`/`stroke_fill` (Pillow >= 8): белый `fill`, чёрный `stroke_fill`; `stroke_width` пропорционален размеру шрифта (~4%), что одновременно даёт и «жирность».
- Раскладка: количество строк = количество слов; вертикальный шаг = (высота поля) / количество слов; каждый рендерится с `anchor="mm"`.
- Автоподбор размера: стартуем с базового размера (зависит от числа строк), пока максимальная ширина слова > 85% ширины — уменьшаем.
- Шрифт: хранится рядом со скриптом — `scripts/GRAYSTROKE REGULAR.otf` (копия из `~/.fonts/`); `ImageFont.truetype` с путём, относительным от файла скрипта.
- Приёмка: прогон на `.tmp/preview-raw.jpg` с примерным названием мода (например, "SIZE IN TOOLTIP"), результат сохранять в `.tmp/` для просмотра пользователем.

## Constraints

- Python 3.12.3, Pillow 10.2.0 (проверено в системе), linux.
- Шрифт: `GRAYSTROKE REGULAR.otf` (Bold-варианта нет — жирность только через обводку); файл лежит рядом со скриптом, `scripts/GRAYSTROKE REGULAR.otf`.
- Выход 900x900 максимум, ratio 1:1, формат PNG.
- В репо нет Python-кода и нет тестовой инфраструктуры — скрипт standalone.
- `scripts/` не игнорируется git'ом — новый каталог будет отслеживаться.

## Open questions

- Точный стиль раскладки (отступы от краёв, плотность шага строк) — подберём на приёмке по картинке, параметры вынесены в константы скрипта.
- Регистр: вписать заглавными (как в логотипе OXI) или как введено? — **решено: как введено** (пользователь передаёт текст, регистр не меняем).
