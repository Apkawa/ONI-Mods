# BuildDoorOverWall

Lets you build doors over walls — place a door where a wall already is, without having to clear the tile first.

## Known issues

- Does **not** work in the sandbox.
- When the top end of the door is placed into a wall, the door **mirrors AirLock** (with ports) in that case.
