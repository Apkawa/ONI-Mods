## Scope

**В scope:**
1. Новый мод `ResourceRemain` (папка `ResourceRemain/` в репозитории, net48, Harmony 2, PLib/UtilLibs, `IsPacked`).
2. **Тултипы строк ресурсов** в двух местах (сейчас их нет):
   - панель «Избранные ресурсы» справа (`PinnedResourcesPanel`, строки из `linePrefab`);
   - экран «Показать все» (`AllResourcesScreen`, строки `ResourceRow`).
   Содержимое тултипа строки ресурса (значения приблизительные, цикл = 600 игровых секунд; формат из draft round 2):
   - **две строки** (число строк фиксированное, hot-swap при удержании безопасен):
     - `Текущий цикл: ±net (−потрачено +добыто)` — текущий (ещё не завершённый) цикл;
     - `Предыдущий цикл: ±net (−потрачено +добыто)` — полностью завершённый предыдущий цикл;
     - заголовки строк — игровые ключи `STRINGS.UI.ELEMENTAL.UPTIME.THIS_CYCLE` / `LAST_CYCLE` («Текущий цикл» / «Предыдущий цикл») + `": "`;
     - значения с единицей измерения ресурса (шт/кг/ккал — форматтеры игры, авто-локализация): `+800шт`, `-800шт`;
   - если чистый прирост за соответствующий цикл **отрицательный** — приблизительный дедлайн `, Циклов: N` (ключ `STRINGS.UI.FORMATDAY`):
     - текущий цикл: N = floor(текущий доступный запас / |скорость за цикл|), где скорость = net_по_ходу_цикла × 600 / прошедшие_секунды_цикла (нормировка на полный цикл);
     - предыдущий цикл: N = floor(запас на конец прошлого цикла / |net прошлого цикла|);
     - при нулевом/положительном приросте дедлайн не показывается; N > 999 или |net| < 0.1 — дедлайн не показывается (шум).
   - строка показывается **всегда** (включая нулевые значения `+0шт (-0шт +0шт)`) с момента, когда есть данные — тултип есть на всех строках ресурсов; строка «Предыдущий цикл» показывается **всегда вместе с текущей**; пока предыдущий цикл ещё не накоплен, значения — прочерк `Предыдущий цикл: -` (обычный символ, локализация не нужна).
   - **Фильтр артефакта после загрузки сейва**: первые секунды после загрузки игра заполняет `WorldInventory` (ресурсы идут с нуля к реальным значениям) — такие данные не учитываются: сэмплы до `T_ref + 30 игровых секунд` отбрасываются, где `T_ref` = время `Game.Instance.OnLoad` (загрузка сейва) или время первой разблокировки паузы (новая игра).
3. **Доработка тултипа счётчика калорий сверху** (`MeterScreen_Rations.OnTooltip`):
   - общая оценка рядом с «Calories Available»: `(N циклов для M дубликантов)`, где M = живые стандартные (едящие) дубликанты, N = floor(доступные калории / (ккал на дубликанта за цикл × M)); ккал на дубликанта — формула игры (`(0 − MinionIdentity.GetCalorieBurnMultiplier()) × DUPLICANTSTATS.STANDARD.BaseStats.CALORIES_BURNED_PER_CYCLE`), т.е. 500 в стандартном режиме, 1000 в выживании (минимум, как в оригинальном тултипе).
   - разбивка по виду еды: к существующей строке каждого вида еды добавляется оценка `(N циклов для M дубликантов)`, где M = живые стандартные дубликанты, которым **разрешена** эта еда (`ConsumableConsumer.IsPermitted(foodId)`); если еда запрещена всем — `(-)`.

**Out of scope:**

- Тултип экрана «Ресурсы» в админ-меню (`ResourceCategoryScreen`) — там тултип уже есть, не трогаем.

## Approach

### Данные по ресурсам
- Игра не ведёт раздельный учёт добычи и расхода по ресурсам: есть `ResourceTracker` (история **общего доступного запаса**, ring buffer 750 точек, 50 трекеров/кадр → окно **~225–425 игровых секунд**, т.е. **меньше цикла**) и `TrackerTool.Instance.GetResourceStatistic(worldId, tag)`. Двух 600-секундных окон из буфера **не получить** (факт R8.3/R10.1), и `Tracker.GetDelta` багован (возвращает value+1) — трекеры для строк не используем.
- **Собственный сэмплер** (KMonoBehaviour с `ISim1000ms`, один экземпляр на мир, спавнится по событию `WorldAdded` + защита на первый тик): раз в игровую секунду берёт `WorldInventory.GetAmount(tag, false)` (то же значение, что показывает строка) по всем ресурсным тегам мира и накапливает по (мир, тег):
  - текущий цикл: **добыто** = Σ положительных шагов, **потрачено** = |Σ отрицательных шагов|, **net** = добыто − потрачено, время начала цикла, последняя величина;
  - предыдущий цикл: те же поля за завершённый цикл + величина запаса на границе цикла (для дедлайна);
  - границы циклов — по глобальному `GameClock` (buckets по 600 с); при переходе граница текущий → предыдущий;
  - **settle-gate**: сэмплы с `time < T_ref + 30` игровых секунд отбрасываются (`T_ref` = `Game.Instance.OnLoad` при загрузке сейва / первая разблокировка паузы `PauseChanged` при новой игре) — исключает «0 → реальные значения» скачок (факты R9).
- Калории (для ресурса-еды) считаются тем же общим механизмом.

### Тултипы строк ресурсов (избранные + «Показать все»)
- Строк-виджетов в этих двух местах **нет в коде** (строки — голые GameObject из prefab; тултипов в коде нет — это и есть «нет тултипа вообще»).
- Harmony **postfix** на `PinnedResourcesPanel.CreateRow(Tag)` и `AllResourcesScreen.SpawnCategoryRow(Tag, MeasureUnit)`: берём gameObject строки, `GetComponent<ToolTip>()` — если есть (сериализован в prefab) — используем, иначе `AddComponent<ToolTip>()`; строковый `OnToolTip` (обёртка существующего, если есть — `OnComplexToolTip` игра игнорирует при заполненном `OnToolTip`); `refreshWhileHovering = true`.
- Строки тултипа: до 2 строк `Текущий цикл: …` / `Предыдущий цикл: …` (число строк стабильно в штатном режиме — hot-swap при удержании работает через `HotSwapTooltipString`; пустая строка игрушкой не злоупотребляется: без данных тултип не строится вовсе).
- Числа форматируем форматтерами игры по единице ресурса (`GameUtil.GetFormattedMass/GetFormattedCalories/GetFormattedUnits` — выбор по tag: `DisplayAsCalories`/`DisplayAsUnits`/масса), т.е. авто-локализация; знаки ставим вручную.
- Все слова — игровые ключи (см. Локализация); кроме них — только цифры, знаки, скобки и `(-)`.

### Тултип счётчика калорий
- `MeterScreen_Rations.OnTooltip` — `protected override string`, строит multi-string тултип (`ClearMultiStringTooltip` + `AddMultiStringTooltip(...)`), уже содержит построчную разбивку по еде.
- Harmony **postfix**: перестраиваем тултип целиком (clear + воспроизведение оригинальных строк + наши дополнения **в строке**), чтобы оценки стояли «рядом с калориями» и на строках еды, как в макете. Пересчёт исходных значений — тем же публичным API (`RationTracker.CountAmount(dict, inventory)`).
- M (всего) = `Components.LiveMinionIdentities` в активном мире, фильтр на стандартную модель (`GameTags.Minions.Models.Standard`).
- M по еде = те же живые стандартные дубликанты, у которых `GetComponent<ConsumableConsumer>().IsPermitted(foodId)`.
- Fallback: весь postfix в try/catch — при сбое тултип остаётся оригинальным (не роняем игру).

### Локализация
- Только существующие ключи игры (`LocString`-поля в рантайме уже локализованы .po игры; свои `.po`/`RegisterForTranslation` не используем — урок v3: незаписанный в таблицу `Strings` `LocString` выводит `MISSING`):
  - «Циклов: N» — `STRINGS.UI.FORMATDAY` (число передаётся строкой, чтобы не было «100.0»);
  - заголовки «Текущий цикл» / «Предыдущий цикл» — `STRINGS.UI.ELEMENTAL.UPTIME.THIS_CYCLE` / `LAST_CYCLE` (+ `": "`);
  - дубликанты — `STRINGS.DUPLICANTS.STATS.SUBJECTS.DUPLICANT` (1) / `DUPLICANT_POSSESSIVE` (2–4) / `DUPLICANT_PLURAL` (5+);
  - `(-)` — чистая пунктуация, **обычный string-константа** (не `LocString`, без регистрации).
- Запрет хардкода RU/EN слов в UI (урок SizeInTooltip).

## Constraints

- FTM **net48** (всем); Harmony = игровая `0Harmony.dll` v2 (не NuGet); PLib 4.19.0 через `UtilLibs` (ProjectReference + `IsPacked=true` → ILRepack в один dll).
- `Directory.Build.props` подмешивает рефы игры с publicizer'ом (protected-члены игры доступны как public) — поэтому можно патчить `protected override OnTooltip` и читать private-ish поля через publicized-рефы/рефлексию `PatchUtil`.
- **Буфер `ResourceTracker` = 750 точек, 50 трекеров/кадр → span ~225–425 игровых секунд (меньше цикла); буфер не сериализуется (пустой после загрузки); `Tracker.GetDelta(secondsAgo)` багован (возвращает `value + 1`) — трекеры для расчёта не используем (факты R8.3, R9, R10.1).**
- **Загрузка сейва:** после `saveManager.Load` игра в паузе; `WorldInventory` заполняется сканом (~N/60 реальных секунд, по одному тегу в кадр), трекеры начинают писать после разблокировки → «0 → реальные значения» скачок в первых игровых секундах; точка опоры — `Game.Instance.OnLoad` (после загрузки, GameClock уже восстановлен) (факты R9).
- `WorldInventory`-значения обновляются инкрементально (могут быть на несколько кадров «устарелыми») — для приблизительной оценки приемлемо.
- Строки в sln не комментируются; `IsPacked` только у мода; один flavor (dev) активен при сборке.
- `DLLLoader` грузит все `*.dll` в папке мода → зависимые dll не кладём в папку (упаковываются).
- Авто-проверка = только сборка; приёмка — пользователем в игре.
- Временные файлы в `.tmp/`, кэши в `.cache/`.
