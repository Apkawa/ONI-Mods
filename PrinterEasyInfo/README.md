Quickly learn what a care package contains: in the telepad's "Choose a scheme / Select a Blueprint" window, each care-package column gets a small book icon in its header — click it and the database (Codex) entry for that item opens right away, no need to search for it yourself.

# Features

* A book icon appears in the header of each care-package column in the telepad's scheme selection window.
* Clicking the icon opens the database (Codex) entry for the item that the care package contains.
* The icon is hidden when the item has no database entry, and it updates automatically whenever a new package is delivered.

# Limitations

* The icon appears only on care-package columns, not on duplicant columns.
* Items without a database entry show no icon.
