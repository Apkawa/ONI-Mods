# 2026-09-26_material-filter-overlay: MaterialFilterOverlay

**Created:** 2026-09-26T23:04:58+03:00

## Scope

Входит в scope:
- Расширение ванильного оверлея «Схема материалов» (F4, режим `TileMode`) подфильтрами по конкретным материалам внутри выбранной категории.
- У каждой категории строка `[+/-] Категория [чекбокс]`; кнопка «+» видна только у **выбранной** категории; по клику раскрывается/схлопывается список всех материалов этой категории с независимыми чекбоксами.
- Выбор 1+ конкретного материала сужает подсветку оверлея до этих материалов.
- Если категория выбрана, но ни один материал не отмечен — ванильная логика (вся категория).
- При переключении на другую категорию: подвыбор обнуляется, дерево схлопывается, «+» переезжает к новой категории.

Не входит в scope:
- Select-all внутри дерева (не нужен).
- Сохранение состояния фильтра между запусками игры (не нужно).
- Новые горячие клавиши, свои режимы оверлея.

## Approach

Ванильный список категорий строится `ToolParameterMenu` (плоский список `ToggleData`), в который нельзя вставить кнопку «+» рядом с конкретной строкой — поэтому мод **заменяет панель легенды** для режима `TileMode`:

- Postfix `OverlayLegend.SetLegend(Mode, bool)` (публичный метод): при `mode.ViewMode() == TileMode.ID` скрываем ванильный `ToolParameterMenu` (поле `filterMenu`, `AccessTools`) и в тот же родитель строим свою панель на PLib.
- Панель: 11 категорий (тот же набор, что `TileMode.CreateDefaultFilters()`: ALL, METAL, BUILDABLE, FILTER, CONSUMABLEORE, ORGANICS, FARMABLE, LIQUIFIABLE, GAS, LIQUID, MISC), один выбранный (ванильное поведение single-select), у выбранной — кнопка «+».
- Дерево материалов: `ElementLoader.FindElements(e => e.materialCategory == <categoryTag>)`, имена через локализацию элементов.
- Логика: заполняем публичный `Game.Instance.tileOverlayFilters` — при отмеченных материалах ставим их теги элементов, иначе ванильное маппинг-правило категории (METAL → `GameTags.Metal + RefinedMetal` и т.д.), затем `Game.Instance.ForceOverlayUpdate()`.
- `OverlayLegend` пересоздаётся при каждой загрузке уровня, `SetLegend` вызывается заново → панель строится автоматически, доп. патчи не нужны.

## Constraints

- TFM net48, референс на игровые dll'ы через `Directory.Build.props`, `0Harmony.dll` игры (v2), PLib 4.19.0 через `UtilLibs`.
- Частные игровые члены читаются через `AccessTools` (паттерн мода SpaceOverlay: postfix + AccessTools, publicizer не нужен).
- Чекбоксы/кнопки/лейблы — PLib (`PCheckBox`, `PButton`, `PLabel`, `PPanel`); имена материалов — локализованные строки элементов (формат проверяется на этапе plan).
- Состояние фильтра живёт в памяти мода, не сохраняется.
